# Healthcare Performance Dashboard

## Project Overview
This project is a Healthcare Performance & Patient Analytics Dashboard built with Power BI. The aim is to help a healthcare organization get a clearer picture of how it is performing and how patients are being served.
The project uses healthcare data containing information about patient visits, departments, diagnoses, revenue, costs, waiting time, patient satisfaction, and patient outcomes across different states in Nigeria.

The dashboard transforms raw healthcare data into meaningful visual insights that allow management to monitor key performance indicators, identify trends, compare departments and locations, and better understand patient experiences.

Key areas analyzed in the dashboard to answer these questions:

- Patient Analytics – patient visits, patient demographics, new and returning patients, and average visits per patient.
- Hospital Operations – department performance, waiting time, patient flow, and operational activity.
- Financial Performance – revenue, costs, and financial trends.
- Patient Experience – satisfaction levels, factors affecting the patient experience and patients waiting time.
- Patient Outcomes – treatment outcomes and overall healthcare performance.
- Geographical Performance – comparison of healthcare performance across different states.
- Which age group represents the largest number of patients?
- Which diagnoses are most common?
- Which state have the highest patient volume?
- How many patients are returning?

Through this project, I worked on data cleaning, data modeling, DAX calculations, and creating interactive Po#wer BI visuals to turn the healthcare data into useful insights that can support better decision-making.

## Dataset
Dataset

The dataset used for this project contains healthcare records from a healthcare organization operating across different states in Nigeria. It includes information about patients, hospital visits, departments, diagnoses, revenue, costs, waiting time, patient satisfaction, and patient outcomes.

The main data areas include:

- Patient information
- Patient visits
- Departments
- Diagnoses
- Revenue and costs
- Waiting time
- Patient satisfaction
- Patient outcomes
- States and locations

The data was cleaned, modeled, and analyzed in Power BI before creating the interactive dashboard.
